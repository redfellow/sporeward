# Claude Code repository guide

Follow [`AGENTS.md`](AGENTS.md) for Sporeward's project scope, OpenSpec process, implementation checks, and repository conventions.

## Pull requests

- For work intended to integrate, use a feature branch and open a pull request targeting `main`; do not push commits directly to `main`.
- Push the branch and create the pull request when the user asks. Do not merge it unless the user explicitly asks.
- Describe the resulting behavior, checks that actually ran, and any unfinished OpenSpec tasks or environment blockers. Do not present an unrun check as passing.
