# Resistance calibration experiment

This pure-rules calibration supports prospective, opt-in server scoring; existing confirmed awards retain their original rules. Parameters are provisional and versioned in [`resistance.ts`](../packages/game/src/resistance.ts). All percentages below are outputs from named synthetic scenarios, not product targets or acceptance thresholds. The current versioned code floor of 25% is a provisional implementation parameter, not an agreed reward target. Run focused checks with `npx vitest run packages/game/src/resistance.test.ts`.

Each accepted contribution records its stable identity, committed cleaning strength, explicit timestamp and one outbreak representative point. Retries and ineligible contacts add nothing. Scheduled treatment delivery must not create another event. Resistance input is 0.23 per full contribution, with a seven-day exponential half-life. The current v1 reward fraction is `0.25 + 0.75 / (1 + resistance)`: its 50% value at resistance 2 is a mathematical property of this provisional curve, not a balancing target; the 25% floor is likewise a provisional code fact, not an acceptance target. Repeated contributions already enter this curve through their cleaning strength; legacy point halving must not be multiplied into it. Cleaning, eligibility and cleanup awards remain separate.

The provisional centre is the representative point with the strongest decayed concentration inside a five-kilometre linear falloff. Candidate history spans 56 days. Existing centres move at most 500 metres per elapsed day; outing references copy the established centre. The weighted-average comparison intentionally exposes the limitation of a mean between separated routines. Concentration chooses the stronger cluster; ties use stable event order. A single circle cannot faithfully represent multiple distant routines. These fixtures establish deterministic behaviour, not geographic product acceptance. The geographic helpers target the Tampere region; coordinate averaging and movement interpolation are not a global dateline model.

Keep event history for identity and historical calculations; the centre horizon does not delete contributions or their decayed familiarity. No live GPS crossing or movement enters the established reference.

Restoration scales linearly with distance up to 10 km and removes at most 80% of remaining resistance. Each distinct collection increases personal collection load by one, recovering exponentially with a one-day half-life from settlement. The successive factor is `1 / (1 + 2 * load)`. Different lab identities and two-hotspot alternation share this load. Frozen offers are maxima capped again at settlement. A zero-resistance collection still counts, but cannot reduce future contributions. Global restoration multiplies preceding contribution inputs known at settlement; subsequently imported history cannot enlarge an earlier restoration. It never changes cleaning or confirmed points. The [server integration](field-labs-integration.md) builds on these functions.

## Four-week scenario measurements (2026-10-21)

Run `node --import tsx scripts/replay/resistance-calibration.mts` from the repository root. Output is deterministic JSON; all coordinates are synthetic representative fixtures. This runner exercises pure rules, not recorded GPS validation, isolated persistence or authoritative collection. Weekly mean and Friday reward are distinct measurements: the mean prices each accepted contact before adding its resistance, while Friday records reward after that week's contributions.

The reference commuter makes two contacts six hours apart each weekday with one persistent target. Ten contributions commit 5.85 full-strength equivalents in week one; later visits commit half strength. Friday reward is measured after that week's contributions, at 20:00. Weekend collection occurs Saturday at noon, with an established reference and synthetic 10 km offer. Local walks make one weekday contact; high-mileage makes four contacts six hours apart and collects a distinct capped-distance lab after each. Multiple targets use three colocated representatives. Replacements use fresh full-strength targets each visit. Alternating hotspots use separated representatives and one weekly collection; this is a geography comparison, not an accessibility claim. These are fixture comparisons, not target attainment. Intensive collection does not sustain full rewards. Fresh replacements retain familiarity but increase resistance faster because they commit full cleaning strength. The multiple-target variant also accumulates more committed strength, so these scenarios are not matched-input comparisons.
